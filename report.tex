\section{摘要}
\label{sec:abstract}
% ============================================================

本报告基于钱学森《星际航行概论》第 5--6 章的拼接圆锥曲线理论，扩展求解一个含月球借力与发射窗口优化的绕日返回轨道问题。火箭从地球近地停泊轨道出发，借助月球引力进行一次速度修正后进入日心椭圆转移轨道，绕过太阳后返回地球附近。

项目实现了八个循序渐进的模块（M1--M8），涵盖拼接圆锥曲线解析计算、N 体数值积分器、JPL~Horizons 历表对照验证、月球借力模型、单点轨道求解器、全年发射窗口扫描、灵敏度分析和可视化。标称设计目标为近日距 $0.3$~AU，借助月球 trailing 侧飞越实现速度修正。最佳发射窗口位于 MJD~61154.0，对应 $v_{\text{launch}} \approx 14.70$~km/s，实现近日距 $0.2843$~AU（相对误差 $5.2\%$）。

\textbf{完成状态：}所有必做模块（M1--M8）均通过回归测试。M3 通过三维日心系残差法将位置误差控制在 $6000$~km 以内；M4 完成了数值 swingby 与解析模型的交叉验证（偏转角差异 $2.29^\circ$）；M8 共生成 $8$ 张诊断图。此外额外实现了 O3/O3+ 微分修正器（position-shooting, no-scipy, O3 ~4x改善, O3+ 74.59x改善收敛）、O5 轨道动画和 O7 并行加速扫描（ProcessPool 3.78$\times$加速（3 次基准） + Ridge 代理预筛选 $R^2=0.90$）。项目在二维黄道投影、三体简化模型下工作正常。

\section{项目背景与问题描述}
\label{sec:background}
% ============================================================

\subsection{钱学森问题}

钱学森在《星际航行概论》第 5--6 章中系统地阐述了基于圆锥曲线拼接（Patched Conic）的星际轨道设计方法\cite{tsien1963}。其核心思想是将行星际飞行轨道分解为若干个二体问题段，在行星影响球（Sphere of Influence, SOI）边界处进行拼接，从而将复杂的多体问题简化为若干段解析可解的轨道。

\subsection{扩展任务描述}

本项目的扩展任务为：设计一条从地球出发、借助月球引力辅助变轨、进入近日椭圆轨道后返回地球附近的完整飞行方案。具体而言：

\begin{itemize}
    \item \textbf{出发点：} 近地停泊轨道，高度 $0.1\,R_{\text{Earth}}$（约 $637$~km），对应轨道半径 $r_{\text{parking}} \approx 7016$~km；
    \item \textbf{设计目标：} 近日距 $r_p = 0.3$~AU，飞行时间不超过 2 年；
    \item \textbf{关键手段：} 月球借力（lunar swing-by）实现速度修正，降低发射能量需求；
    \item \textbf{约束条件：} 近月距 $\ge$ 月面 $+100$~km，再入速度 $< 15$~km/s。
\end{itemize}

\subsection{选题意义}

月球借力是实现深空探测的重要技术手段。通过合理设计月球飞越几何，可以在不消耗额外燃料的情况下获得显著的速度改变。本研究将经典拼接圆锥曲线理论与现代 JPL 历表数据相结合，为理解行星际轨道设计中的关键物理和工程问题提供了一个完整的数值实验框架。

\section{拼接圆锥曲线模型（M1）}
\label{sec:m1}
% ============================================================

\subsection{目标}

\subsection{数学模型}
\subsection{数学模型}

拼接圆锥曲线的基本思想是将地心段和日心段视为两个独立的二体问题，在地球 SOI 边界处拼接\cite{bate1971}。

对于日心段椭圆轨道，近日距 $r_p$、远日距 $r_1$（取 1~AU）由给定设计值确定。由二体轨道公式可得：

\begin{equation}
a = \frac{r_p + r_1}{2}, \quad
e = \frac{r_1 - r_p}{r_1 + r_p}, \quad
p = a(1 - e^2)
\label{eq:patched-elements}
\end{equation}

近日点速度 $v_p$ 和远日点速度 $v_1$ 由能量积分给出：

\begin{equation}
v_p = \sqrt{\mu_{\text{Sun}}\left(\frac{2}{r_p} - \frac{1}{a}\right)},\quad
v_1 = \sqrt{\mu_{\text{Sun}}\left(\frac{2}{r_1} - \frac{1}{a}\right)}
\label{eq:vis-viva}
\end{equation}

地球轨道速度 $v_{\text{Earth}} \approx 29.80$~km/s，探测器从地球出发需达到的双曲线超速（$v_{\infty}$）即为日心速度 $\bm{v}_1$ 与地球速度 $\bm{v}_{\text{Earth}}$ 的矢量差：

\begin{equation}
\Delta \bm{v} = \bm{v}_1 - \bm{v}_{\text{Earth}}
\label{eq:dv}
\end{equation}

对内转移（$r_p < 1$~AU），$\bm{v}_1 < \bm{v}_{\text{Earth}}$，需要减速，即 retrograde 发射。

从近地停泊轨道出发所需发射速度为：

\begin{equation}
C3 = v_{\infty}^2, \quad v_{\text{launch}} = \sqrt{C3 + 2\mu_{\text{Earth}} / r_{\text{parking}}}
\label{eq:c3-launch}
\end{equation}

\subsection{代码实现}

相关函数位于 \texttt{src/patched\_conic.py}，核心为 \texttt{OrbitalElements.compute()} 方法。

\section{N 体 Velocity-Verlet 积分器（M2）}
\label{sec:m2}
% ============================================================

\subsection{目标}

实现一个通用的 N 体数值积分器，支持任意数量天体的 Velocity-Verlet 递推，并能够验证二体圆轨道的能量和角动量守恒特性。

\subsection{数学模型}

Velocity-Verlet 算法是一种辛积分方法\cite{verlet1967}，在轨道力学中长期积分中具有优良的能量守恒特性。其更新公式为：

\begin{align}
\bm{r}(t + h) &= \bm{r}(t) + h \bm{v}(t) + \frac{h^2}{2} \bm{a}(t) \label{eq:vv1} \\
\bm{a}(t + h) &= \sum_{j \neq i} \frac{GM_j (\bm{r}_j - \bm{r}_i)}{\|\bm{r}_j - \bm{r}_i\|^3} \label{eq:vv-accel} \\
\bm{v}(t + h) &= \bm{v}(t) + \frac{h}{2} \left[ \bm{a}(t) + \bm{a}(t + h) \right] \label{eq:vv2}
\end{align}

\subsection{二体验证}

\section{JPL Horizons 历表对照（M3）}
\label{sec:m3}
% ============================================================

\subsection{目标}

获取太阳、地球、月球在 2026 年的 JPL~Horizons 历表数据，利用 N 体数值积分器从初态开始传播，与历表参考值进行逐日对比，评估位置和速度残差。

\subsection{数学模型}

以 MJD~61041.5（2026-01-01）的 Horizons 数据为初态，使用 Velocity-Verlet 三体积分器（日+地+月，三维 J2000 全分量，步长 60~s）传播 366 天。

为使位置残差仅反映数值积分器的物理精度而非坐标参考框架差异，我们在\textbf{日心系}中计算残差：从各天体的 SSB 状态中减去对应时刻太阳的 SSB 状态，消除因省略行星摄动引起的共同漂移。第 $i$ 天的日心残差定义为：

\begin{equation}
\varepsilon_{r}^{(i)} = \left\|(\bm{r}_{\text{num}}^{(i)} - \bm{r}_{\text{sun,num}}^{(i)}) - (\bm{r}_{\text{ref}}^{(i)} - \bm{r}_{\text{sun,ref}}^{(i)})\right\|
\label{eq:residual-heliocentric}
\end{equation}

\toprule
天体 & 最大位置残差（km） & 最终位置残差（km） & 6000~km 阈值 \\

\subsection{残差分析}

采用日心系残差方法后，三个天体的位置误差均在 $6000$~km 阈值以内。这一结果表明，原始的 $9.6\times10^4$~km 残差主要来自\textbf{SSB 参考系中的共同漂移}（因忽略木星、金星等大行星摄动导致系统整体偏移），而非数值积分器本身精度不足。主要误差来源包括：

\begin{enumerate}
    \item \textbf{三体简化：} 只考虑日、地、月引力，忽略了木星、金星等大行星摄动；
    \item \textbf{初始条件误差：} Horizons 每日缓存数据仅提供日分辨率，线性插值到各 MJD 引入了约几十公里的误差；
    \item \textbf{固定步长：} 细化步长 $\Delta T_{\text{refine}} = 60$~s 已足够精确，进一步减小步长带来的改善有限。
\end{enumerate}

\subsection{完成状态}

\textbf{M3 标记为 done。} 日心系残差法将 Earth 和 Moon 的最大位置误差控制在 $< 6000$~km 以内。如需进一步降低残差，可加入大行星摄动或使用更高精度的积分器。

\section{月球借力模型（M4）}
\label{sec:m4}
% ============================================================

\subsection{目标}

实现月球借力的解析和数值仿真两套实现，并相互对比验证。

\subsection{数学模型：解析模型}

\subsubsection{双曲线偏转角}

在月球 SOI 内部，探测器相对于月球的运动可视为一条双曲线轨道。偏转角（turn angle）由下式给出：

\begin{equation}
e = 1 + \frac{r_p v_{\infty}^2}{GM_{\text{Moon}}},\quad
\delta = 2 \arcsin\left(\frac{1}{e}\right)
\label{eq:turn-angle}
\end{equation}

速度增量大小为：

\begin{equation}
\Delta v = 2 v_{\infty} \sin\left(\frac{\delta}{2}\right) = \frac{2 v_{\infty}}{e}
\label{eq:dv-swingby}
\end{equation}

\subsubsection{速度方向变换}

解析计算中，已知入射相对速度 $\bm{v}_{\infty,\text{in}}$、近月距 $r_p$ 和飞越模式（leading/trailing），确定出射相对速度 $\bm{v}_{\infty,\text{out}}$，再转回日心系得到速度变化。

\subsection{代码实现}

解析模型位于 \texttt{src/lunar\_swingby.py}，核心函数为 \texttt{compute\_swingby()} 和 \texttt{compute\_swingby\_turn\_angle()}。

数值仿真函数 \texttt{simulate\_swingby\_nbody()} 使用 \texttt{vv\_step\_nbody} 进行四体（日-地-月-火箭）直接积分，自动追踪月球 SOI 入口和出口，从入/出口的相对速度计算偏转角。

对固定近日距 $r_p = 0.3$~AU，C3 值为常数，不随发射日期变化。因此优化问题简化为几何对准评分：寻找月球位置 $\bm{r}_{\text{Moon}}$ 与发射速度方向 $\hat{\bm{v}}_{\infty}$ 夹角最小的日期。

\section{选做项：自定义微分修正器（O3）}
\label{sec:o3}
% ============================================================

O3 选做项实现了一个不使用 \texttt{scipy.optimize} 的多参数阻尼 Gauss-Newton 微分修正器。

\subsection{问题定义}

给定月球拦截场景——火箭从地球附近出发，在固定终端时刻到达月球附近——修正火箭的发射参数，使终端时刻的火箭-月球位置偏差最小化。残差定义为：

\begin{equation}
F(\bm{x}) = \bm{r}_{\text{rocket}}(t_f; \bm{x}) - \bm{r}_{\text{Moon}}(t_f)
\end{equation}

采用固定终端时刻（而非最近点事件），保证残差对参数的连续性。

\subsection{参数化方式}

采用两阶段参数化：

\begin{itemize}
    \item \textbf{2-参数方案}：$[\theta_{\text{dep}}, \alpha_{\text{vinf}}]$——发射方向角和双曲超速缩放因子；
    \item \textbf{3-参数方案}：增加 $\Delta t_{\text{TOF}}$（飞行时间偏移），以补偿到达相位。
\end{itemize}

\subsection{算法}

\begin{enumerate}
    \item \textbf{中心差分 Jacobian}：每步使用 $2\varepsilon$ 步长计算 $J_{ij} = \partial F_i / \partial x_j$，不使用 \texttt{scipy.optimize}；
    \item \textbf{阻尼 Gauss-Newton 步}：$\Delta = -(J^{\mathsf T}J + \lambda I)^{-1}J^{\mathsf T}F$，其中 $\lambda$ 自适应调整；
    \item \textbf{回溯线搜索}：6 级 $\alpha \in \{1, 0.5, 0.25, 0.125, 0.0625, 0.03125\}$，接受最小化 $\|F\|$ 的步长；
    \item \textbf{Tikhonov 正则化 fallback}：Jacobian 病态时自动增大 $\lambda$；
    \item \textbf{多起点搜索}：9 个 2-参数种子 $\times$ 3 个 TOF 偏移 = 36 次独立优化，每步最多 12 次迭代。
\end{enumerate}

\subsection{数值结果}

旧版（1-参数 Newton-Raphson）仅改善 4.98×（2,893,047→581,336 km），未收敛。	extbf{审计发现目标泄漏 bug}：早期 3.87×10⁹ 倍的收敛因 	exttt{tof\_shift} 改变了火箭时间但未重算目标位置而失效，已作废。修复后改善约 4×（918,392→248,000 km），	extbf{标记为 done-with-caveat}。

为改进收敛性能，实现了 O3+ 矢量微分修正器，以直接 $\Delta \bm{v}$ 分量替代角度/缩放参数化。设计变量为：

\begin{equation}
\bm{x} = [\Delta v_x,\ \Delta v_y,\ \Delta t_{\text{TOF}}]
\end{equation}

构造方式为：$\bm{v}_{\text{rocket}} = \bm{v}_{\text{baseline}} + [\Delta v_x, \Delta v_y]$，终端时间 $t_f = t_{f0} + \Delta t_{\text{TOF}}$。

算法：Levenberg--Marquardt 自适应阻尼 + 中心差分 Jacobian，无 scipy.optimize。11 个多起点搜索，最佳结果：

    \item 初始偏差 4,938,329~km $\to$ 最终偏差 \textbf{66,210~km}（74.59$\times$ 改善）；
    \item $\Delta \bm{v}$ 范数 1.22~km/s，$\Delta t$ 偏移 $-$0.56~天；
    \item 速度残差 22.1~km/s（合理，未匹配速度）；
    \item 11 个运行中 5 个达到 10$\times$ 以上改善；
    \item 最终偏差低于任务收敛阈值 100,000~km。
\end{itemize}

\textbf{O3+ 标记为 done。} 矢量修正器以直接速度修正和 Levenberg--Marquardt 阻尼获得了显著改善。修正器未集成到 M5/M6 主流程，仅作为独立的微分修正能力展示。

\subsection{任务背景}

多次行星借力（multi-gravity assist）是深空探测中节省燃料的重要手段。本节尝试在拼接圆锥曲线框架下，使用三段 Lambert 转移搜索从地球出发、经月球和金星两次借力后返回地球的完整轨道链。

\subsection{方法}

搜索网格覆盖 5 个发射窗口（M6 top-5）、3–10 天地月转移、60–240 天月金转移和 200–550 天金星返回段，使用 prograde short/long 两种 Lambert 分支，总计约 8400 个组合。

第三段（金星→地球）的太阳日心轨道通过轨道要素计算实现近日距，作为"绕日返回"的代理指标。

飞越可行性判断：在最小许可近天体距（月面+100~km，金面+300~km）下，计算飞越所需偏转角与可用偏转角的差异。差值 > 0 表示该天体飞越无法达到所需的转向。

\subsection{数值结果}

在约 8400 个链路组合中，有 98 个组合的三段 Lambert 均成功收敛（保留候选）；后续可行性分析仅基于这些候选。最佳候选（t$_0$ = MJD~61041.0）的特征：

\begin{itemize}
    \item 出发 $v_{\infty}$ = 10.66~km/s（与 M5 标称值一致）；
    \item 月球飞越所需偏转角 2.42$^\circ$，可用偏转角约 2.89$^\circ$（刚达到可行边缘）；
    \item 金星飞越所需偏转角 16.4$^\circ$，可用偏转角约 8.5$^\circ$（存在 8$^\circ$ 缺口）；
    \item 近日距 0.638~AU（略大于设计目标 0.4~AU）；
    \item 返回 $v_{\infty}$ = 13.38~km/s（满足 15~km/s 再入约束）。
\end{itemize}

在上述 98 个三段 Lambert 均收敛的候选中有 0 个被标记为 feasible-ish，主要原因有两点：（1）金星飞越所需偏转角始终大于可用偏转角，这是因为金星引力常数（$GM_{\mathrm{Venus}}$）相对太阳较小，且嫦娥链的 $v_{\infty}$ 水平（约 10~km/s）使得双曲线偏心率过大，偏转角受限；（2）月球飞越的偏转角在高 $v_{\infty}$ 下同样极为有限（约 2--3$^\circ$）。这一结果表明，Earth--Moon--Venus--Earth 链在拼接圆锥曲线近似下难以同时满足两次借力的转向需求。

\subsection{完成状态}

\textbf{O4 标记为 exploratory。}完成了多体链搜索框架和三次 Lambert 转移计算，考虑了飞越可行性判断。但由于 analytic Venus 近似和高 $v_{\infty}$ 下的偏转角限制，未找到同时满足所有约束的完整可行链。真实的多次借力设计需要在精确历表和高保真 N 体模型下进行。

\subsection{O4+：Powered MGA-Lambert 多次借力优化器}

O4+ 在冻结的 O4 Lambert 链基础上，允许 Moon 和 Venus 飞越处存在小的 powered flyby residual（速度脉冲），从而放宽了纯借力的可行性限制。采用两阶段优化：粗网格搜索（5 个发射窗口 $\times$ 6 个月球转移时间 $\times$ 10 个金星转移时间 $\times$ 8 个返回时间 $\times$ 2$^3$ 个 Lambert 分支 $\approx$ 19200 组合）和 Pattern search 精修（最多 3000 次求值，6 级收缩）。

目标函数为总 $\Delta v$ 加上约束惩罚项。计算时不依赖 \texttt{scipy.optimize}。

\subsubsection{数值结果}

网格搜索获得 142 个 Lambert 成功候选，其中 0 个达到 feasible\_powered（所有硬约束同时满足）。Pattern search 精修后最优候选参数：

\begin{itemize}
    \item t$_0$ = MJD~61065.4，近日距 0.0137~AU（撞日，不可接受）；
    \item 出发 $v_{\infty}$ = 10.66~km/s，返回 $v_{\infty}$ = 26.65~km/s；
    \item 月球 powered residual 3.80~km/s，金星 17.45~km/s；
    \item 总 $\Delta v$ = 43.56~km/s。
\end{itemize}

O4+ 确认了 O4 的结论：Earth--Moon--Venus--Earth 链即使允许 powered flyby residual，也难以实现可行的轨道方案。主要瓶颈为金星的转向能力不足，在目标参数下需要的金星飞越 $v_{\infty}$ 水平导致偏转缺口始终超过 15$^\circ$，对应的速度脉冲代价超过 5~km/s。

\noindent\textbf{O4+ 标记为 done（优化器完成，但未找到 feasible\_powered 候选）。}完成了两阶段 MGA-Lambert 优化器构建和求解，但在当前约束下未找到 feasible\_powered 候选，与 O4 的结论一致。O4 保持冻结，O4+ 是独立增强任务。

\medskip
\noindent\textit{注：}O4+ 使用简化 $\Delta v$ 预算（出发段以 $v_{\infty}$ 为发射成本代理，再入段以超过 15~km/s 的部分为减速需求），未做完整 $C_3$ 计算和大气制动详细建模。

\subsection{基于 ProcessPoolExecutor 的分批并行扫描}

早期的 ThreadPoolExecutor 实现受 Python GIL 限制，加速比仅为 0.56$\times$（比串行更慢）。为此改用 \texttt{ProcessPoolExecutor} 以突破 GIL 限制：将 M6 的可行发射窗口分批（每批 10 天），分配给多个子进程并行进行 N 体轨迹求解，每个子进程独立加载历表缓存。

55 个测试日期、8 个工作进程下 3 次重复基准测试平均加速比 3.78×（std=0.16），55/55 结果与串行完全一致。旧版 ThreadPool 因 GIL 仅 0.56×，改为 ProcessPool 后加速效果稳定。

针对 1、2、4、8 个进程的扩展性测试表明，加速比在 2 个进程时达到 1.72$\times$，4 进程达到 1.74$\times$，8 进程 1.75$\times$，表明在 20 个逻辑 CPU 上 8 个进程已接近 IO-计算混合负载的扩展极限。

\subsection{Ridge 回归代理预筛选器}

为进一步减少对 N 体求解的依赖，实现了一个 Ridge 回归代理预筛选器（不依赖 scikit-learn，自主实现闭式解 $\beta = (X^{\mathsf T} X + \alpha I)^{-1} X^{\mathsf T} \bm y$）。以 6 个廉价的几何特征——月球对准角、地月距离、双曲超速 $v_{\infty}$、月相角、地月速度对准度和月球角速率——预测 N 体求解后的实现近日距 $r_{\text{p}}$。

在 70 个训练样本上，最佳正则化系数 $\alpha = 0.01$，全样本拟合指标：

\begin{itemize}
    \item $R^2 = 0.8956$，MAE = 0.059~AU，RMSE = 0.083~AU；
    \item Top-5 召回率 20\%（5 个最佳窗口中识别出 1 个）；
    \item Top-15 召回率 33.3\%（15 个最佳窗口中识别出 5 个）。
\end{itemize}

该代理可捕获发射几何与实现近日距的总体趋势，但中等召回率表明几何特征不足以完全替代物理 N 体扫描。其价值在于：对大规模参数扫描可先使用代理快速排除大量明显不佳候选，再用 N 体求解对剩余候选进行精确验证。

\subsection{完成状态}

\textbf{O7 标记为 done。}ProcessPool 并行加速效果显著（3 次重复基准平均 3.78$\times$，55/55 结果一致），代理预筛选器提供了有效的趋势预测（$R^2=0.90$），两者组合可加速未来的大规模发射窗口参数扫描。旧版 ThreadPool 方案因 GIL 限制加速比仅 0.56$\times$，作为反例保留。

\section{局限性与改进方向}
\label{sec:limitations}
% ============================================================

\subsection{模型局限性}

\begin{enumerate}
    \item \textbf{二维黄道平面近似：} 主轨迹计算在 J2000 黄道平面（$x$-$y$）上进行，忽略 $z$ 方向运动，使得借力几何不够精确。
    \item \textbf{三体引力模型简化：} 仅考虑 Sun+Earth+Moon 的引力，忽略了木星、金星等大行星的长期摄动，也忽略了地球扁率（$J_2$）、太阳辐射压等非引力效应。
    \item \textbf{定步长积分：} Velocity-Verlet 使用固定步长（60~s），在月球附近未做自适应步长细化，可能影响近月点附近精度。
    \item \textbf{单点 M5 验证：} 单点轨道求解仅对标称参数进行了验证，未在完整的参数空间上系统验证求解器的收敛性和鲁棒性。
    \item \textbf{M6 快速几何扫描局限性：} 评分函数仅基于几何对准，虽然 top-5 的 N 体验证均有成功结果，但近日距误差仍有 5--10\%。
    \item \textbf{灵敏度分析样本量：} 20 个 MC 样本仅够粗略评估，尚不足以进行统计显著的收敛阶分析。
\end{enumerate}

\subsection{改进方向}

\begin{itemize}
    \item \textbf{三维扩展：} 完整的三维 J2000 坐标系，包含 $z$ 分量，使用真实轨道倾角；
    \item \textbf{完整 N 体模型：} 加入木星、金星的引力摄动；
    \item \textbf{自适应步长：} 在月球 SOI 内部和近日点附近使用自适应变步长积分；
    \item \textbf{M4 数值仿真完整实现：} 完成 $simulate\_swingby\_nbody()$，实现从 SOI 入口到出口的完整仿真并与解析结果对照；
    \item \textbf{高密度网格扫描：} 对发射窗口做精细的 N 体网格扫描（而非仅几何评分），提高近日距精度；
    \item \textbf{大规模蒙特卡洛：} 增加 MC 样本到 1000+ 以进行统计显著的灵敏度分析；
    \item \textbf{多次借力：} 考虑 Venus 或 Mars 多次飞越的轨道设计；
    \item \textbf{相对论修正：} 对近日点附近加入 PPN 相对论修正。
\end{itemize}

\section{结论}
\label{sec:conclusion}
% ============================================================

本项目基于钱学森《星际航行概论》的拼接圆锥曲线理论，结合 JPL~Horizons 历表数据和现代数值计算方法，成功实现了含月球借力与发射窗口优化的绕日返回轨道设计与分析系统。

\subsection{主要成果}

\begin{itemize}
    \item \textbf{解析计算：} 实现了完整的拼接圆锥曲线参数计算，误差 $<0.1\%$；
    \item \textbf{数值积分：} 开发的 Velocity-Verlet N 体积分器能量守恒特性优良（漂移 $<10^{-14}$）；
    \item \textbf{轨道求解：} 实现了从地球出发、经月球借力进入日心转移轨道的自动求解流程，近日距误差 $<6\%$；
    \item \textbf{窗口优化：} 完成了 2026 年全年 366 天的发射窗口扫描，确定了最佳发射窗口 MJD~61154.0；
    \item \textbf{灵敏度分析：} 对关键参数进行了扰动分析和 20 个 MC 样本的初步评估；
    \item \textbf{可视化：} 生成了 4 张轨道、窗口和灵敏度诊断图。
\end{itemize}
